异形场地模块独立调试

gantang-project.v1

入口

这个目录是从主球场设计器里单独复制出来的异形场地模块，包含扣除区域、比例标定、铺格算量、JSON/CSV 导出和 iframe 通信 demo。

打开独立设计器 打开宿主 Demo

调试重点

  • 铺装区域和扣除区域是否闭合、是否正确参与净面积与格子计算。
  • 比例尺是否从待校准变为已校准，导出 JSON 中 scale.needsCalibration 是否为 false。
  • 导出 JSON / CSV 是否真实触发下载，并包含 gantang-project.v1 与算量字段。
  • 宿主 Demo 的 get-project、set-scale、set-mode 消息是否正常返回。
